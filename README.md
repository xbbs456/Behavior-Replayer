# 行为回放器（Behavior Replayer）

> **v1.0.2** — 一款 Android 操作回放工具：**录制一次，永久回放**。支持录制点击、滑动（含曲线/摩擦轨迹）、输入文本等操作，配合定时执行或悬浮球一键触发，无需 Root（基于无障碍服务实现）。

## 📦 源码下载

源码 zip 请前往 **Release** 下载（APK 也发布在 Release 中，可直接安装）。

## ✨ 功能特性

- 🎙 **手势录制**：悬浮窗录制点击与滑动，滑动支持**完整轨迹**（画圈、来回摩擦 1:1 复现），录制速度与真实操作一致
- ⏱ **定时执行**：可选定时（每天重复/单次），也可关闭定时改为纯手动触发
- 🪄 **悬浮球**：一键回放绑定的任务；回放中点按球体可**随时终止**（▶/⏹ 图标切换）
- 🎬 **动作编排**：打开应用、点击（录制/单次取点）、滑动（录制）、输入文本、等待、返回键、主页键；每个动作可设置**完成后延迟**
- 🔁 **重复次数**：整组动作可重复 N 次（如自动点赞 10 次）
- ⚡ **立即回放**：不保存直接测试当前动作
- 🔋 **保活引导**：主界面状态卡实时检测无障碍 / 省电策略 / 后台上锁 / 悬浮窗权限，一键跳转设置

## 📱 使用流程

1. 安装 APK，打开应用
2. 按主界面状态卡引导：开启无障碍 → 省电策略设「无限制」→ 后台上锁 → 允许悬浮窗
3. 新建任务 → 添加动作（录制/点击/滑动/输入…）
4. 保存后：到点自动回放，或用悬浮球一键触发

## 🔧 构建

依赖：JDK 8+、Android SDK build-tools 29.0.3（aapt / zipalign / apksigner）、Android platform android.jar、R8/D8（r8.jar）。
构建产物：`行为回放器.apk`，**可直接分享/发布给他人安装**。
